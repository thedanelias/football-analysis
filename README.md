## Modelling xG using player-specific abilities

## Description
This project creates a new xG model using individual player ability to affect the 'baseline' xG caclulated. Better finishers see an increase in their xG, while worse finishers will see a decrease.

## Usage
Simply run main.py. Figures modeling the player-specific xG against the baseline xG are available in 'resources/figures'. CSV files generated are available under '/resources/'
